The Unify wordmark with its tagline lockup.

Set "Unify" in Playfair Display 900 (`wordmark`), followed by a full stop in `green`. Never retype it in another font, stretch, skew, outline or add a shadow. Keep clear space equal to the height of the U on all sides.

The tagline BUILT FOR THE ONES WHO BUILD. uses `tagline`: Playfair Display 600, uppercase, 0.2em tracking. It uses the same typeface as the wordmark, never DM Sans. Place it directly beneath the wordmark, left-aligned to the U, at about 30% of the wordmark's size (11px under a 36px wordmark).

The consumer provides the background: `off-white` for the light variant, `near-black` for the reversed one. Text on them is `near-black` and `off-white`.

Do not use `green` for the wordmark text itself, only the full stop.
