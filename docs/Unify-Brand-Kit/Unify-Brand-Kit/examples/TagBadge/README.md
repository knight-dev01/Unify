Tags label a topic; badges mark a version or state.

Tags: `micro` (DM Sans 11px, weight 500), `space-1` by `space-3` padding, `radius-pill`, `tag-bg` fill, `text-muted` text. The green variant uses `green-tint` fill, `green-tint-border` outline and `green-text`. The consumer provides a short text label.

Badges: DM Sans 10px weight 700, `radius-pill`. Green badge: `green` fill with `on-green` text. Neutral badge: `surface-2` fill with `text-muted`.

Colour never carries meaning alone. A badge always says the word ("v2", "Done"). Use the green variant for at most one or two items in a row.
