A recall prompt at the end of a topic that hides its answer until the student taps Reveal.

The consumer provides a category label (Mechanism, Application), the question and the answer.

- Card: `surface`, 1px `border`, `radius-lg`, `shadow-card`, `space-5` padding.
- Label: `eyebrow` in `text-muted`. Question: `note-panel-title`.
- Answer: `surface-2` panel, `radius-md`, hidden by default.
- Reveal: secondary Button, label toggles between "Reveal answer" and "Hide answer".

Never print the answer under the question without a tap; that removes the recall.
