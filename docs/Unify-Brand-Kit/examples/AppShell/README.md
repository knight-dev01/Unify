The product shell: top bar, one dark hero banner, section titles, cards, and bottom navigation. The website uses the same shell without the bottom nav.

The consumer provides the greeting or headline, the eyebrow context (level, semester, week), the progress value, and the card content.

- Top bar: `wordmark` at 22px on `bg`, avatar on the right.
- Hero: `invert-bg`, `radius-xl`, `eyebrow` in `invert-accent`, `h1` in `invert-text`, one line in `invert-muted`, progress track in `invert-border` with a `green` fill. One per page.
- Section titles: `h2`. Stat cards: `surface`, `radius-lg`, number in Playfair 900, label in `micro` `text-muted`. Course cards: `surface`, `radius-xl`, `shadow-card`, `h3` title.
- One primary button per screen.
- Bottom nav: `surface` with a top `border`, labels in `sm`, active item on a `green-tint` pill. Hidden in reading mode.

Don't put more than one hero on a page, don't use green for more than the active item, progress and one CTA.
